# Этап 1. Минимальный прототип с конфигурацией

## Общее описание

CLI-приложение для визуализации графа зависимостей пакетов Alpine Linux (apk). На данном этапе реализован минимальный прототип с конфигурацией через INI-файл. При запуске приложение выводит все настраиваемые параметры в формате ключ-значение и обрабатывает ошибки конфигурации.

## Описание всех функций и настроек

### Конфигурационный файл (`src/config.ini`)

Источником настраиваемых пользователем параметров является INI-файл. Секция `[Settings]` содержит следующие параметры:

| Параметр | Описание | Тип |
|----------|----------|-----|
| `package_name` | Имя анализируемого пакета | строка |
| `repo_url` | URL-адрес репозитория или путь к файлу тестового репозитория | строка |
| `test_mode` | Режим работы с тестовым репозиторием | True/False |
| `package_version` | Версия пакета | строка |
| `max_depth` | Максимальная глубина анализа зависимостей | целое число |

### Модуль `config_parser.py`

Класс `ConfigParser` — загрузка и валидация конфигурации.

- **`__init__(file_path: str)`** — инициализация с путём к файлу конфигурации.
- **`load_config()`** — загрузка и валидация конфигурации. Выбрасывает:
  - `FileNotFoundError`, если файл не найден.
  - `ValueError`, если отсутствует секция `[Settings]` или обязательный параметр.
  - `ValueError`, если `max_depth` не целое число или `test_mode` не True/False.
- **`display_config()`** — вывод всех параметров в формате ключ-значение.

### Обработка ошибок

- Отсутствие файла конфигурации → `FileNotFoundError`.
- Отсутствие секции `[Settings]` → `ValueError`.
- Отсутствие обязательного параметра → `ValueError`.
- Неверный тип данных → `ValueError`.

## Описание команд для сборки проекта и запуска тестов

### Запуск приложения

```bat
run.bat
```

или

```sh
python src\main.py
```

### Запуск тестов

```sh
python -m pytest tests/ -v
```

Тесты покрывают:
- Загрузку конфигурации и проверку значений параметров.
- Ошибку при отсутствии файла конфигурации.
- Ошибку при отсутствии секции `[Settings]`.

## Примеры использования

### Пример конфигурации (`src/config.ini`)

```ini
[Settings]
package_name = busybox
repo_url = https://dl-cdn.alpinelinux.org/alpine/edge/main
test_mode = False
package_version = 1.36.1-r15
max_depth = 3
```

### Пример вывода при запуске

```
Параметры конфигурации
package_name: busybox
repo_url: https://dl-cdn.alpinelinux.org/alpine/edge/main
test_mode: False
package_version: 1.36.1-r15
max_depth: 3
```
