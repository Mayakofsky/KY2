# Этап 2. Сбор данных о зависимостях пакетов Alpine Linux

## 1. Общее описание

Инструмент визуализации графа зависимостей для пакетов Alpine Linux (apk).
На данном этапе реализована логика сбора прямых зависимостей анализируемого
пакета заданной версии из репозитория Alpine Linux.
Использование сторонних библиотек и штатных менеджеров пакетов исключено —
разбор и извлечение данных производятся напрямую из оглавления репозитория
`APKINDEX.tar.gz`.

## 2. Описание всех функций и настроек

### Конфигурационный файл (`src/config.ini`)

Источником настраиваемых параметров является INI-файл со следующими ключами:

| Параметр | Описание | Тип |
|---|---|---|
| `package_name` | Имя анализируемого пакета | строка |
| `repo_url` | URL-адрес репозитория Alpine Linux | строка |
| `test_mode` | Режим работы с тестовым репозиторием | True/False |
| `package_version` | Версия пакета | строка |
| `max_depth` | Максимальная глубина анализа зависимостей | целое число |

### Модуль `config_parser.py`

* `ConfigParser(file_path: str)` — класс для загрузки и валидации параметров.
* `load_config()` — чтение INI-файла и проверка корректности всех полей.
* `display_config()` — вывод параметров на экран в формате ключ-значение.

### Модуль `dependency_collector.py`

* `DependencyCollector(repo_url: str)` — класс для извлечения зависимостей.
* `_fetch_index_content() -> str` — загружает архив `APKINDEX.tar.gz` по HTTP,
  распаковывает его в оперативной памяти и возвращает текст файла `APKINDEX`.
* `get_direct_dependencies(pkg_name: str, pkg_ver: str) -> list[str]` —
  парсит текстовые блоки пакетов, сопоставляет имя `P:` и версию `V:`,
  извлекает и разделяет список прямых зависимостей из строки `D:`.

### Обработка ошибок

* `FileNotFoundError` — отсутствие файла конфигурации.
* `ValueError` — некорректные типы параметров, отсутствие секции `[Settings]`.
* `ValueError` — отсутствие пакета указанной версии в репозитории.
* Сетевые ошибки и недоступность репозитория выводятся в `stderr`.

## 3. Описание команд для сборки проекта и запуска тестов

### Запуск приложения

```bat
run.bat
```

или

```sh
python src\main.py
```

### Запуск тестов

```bat
test.bat
```

или

```sh
python -m pytest tests/ -v
```

Тесты проверяют:
* Загрузку и валидацию конфигурации `config.ini` и обработку ошибок.
* Корректный парсинг индекса `APKINDEX` и извлечение зависимостей.
* Случаи пакетов без зависимостей.
* Ошибки при отсутствии пакета или несовпадении версии.

## 4. Примеры использования

### Пример конфигурации (`src/config.ini`)

```ini
[Settings]
package_name = busybox
repo_url = https://dl-cdn.alpinelinux.org/alpine/v3.20/main/x86_64
test_mode = False
package_version = 1.36.1-r31
max_depth = 3
```

### Пример вывода при запуске

```text
Прямые зависимости пакета busybox (1.36.1-r31):
- so:libc.musl-x86_64.so.1
```
